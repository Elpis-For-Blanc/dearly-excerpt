Dearly Excerpt

원하는 문장만 넣어 꾸미고 이미지로 저장하는 발췌 메이커. 입력한 데이터는 기본적으로 현재 브라우저에만 저장됨.

1. 발췌문

소설 모드는 일반 발췌 형식. 화자는 이름: 형식으로 입력하면 자동 구분됨.

✦ 소설 모드

2. 카드 정보 (선택)

전부 비워도 됨. 입력된 항목만 결과 카드에 표시됨.

3. 화자 설정

화자별 색상과 채팅 모드에서의 말풍선 방향을 설정할 수 있음.

4. 디자인

TTF · OTF · WOFF · WOFF2 지원. 업로드한 폰트는 현재 발췌 저장 데이터에 포함할 수 있음.

5. 발췌 이미지

배경과 별개로 발췌 옆에 이미지를 넣을 수 있음. 큰 이미지는 카드에 맞는 크기로 자동 조절되고, 미리보기 이미지를 직접 드래그해 보이는 부분을 옮길 수 있음.

6. 배경

7. 디자인 · 배경 프리셋

현재 디자인과 배경만 따로 저장해두고 다른 발췌에 그대로 적용할 수 있음. 발췌문, 카드 정보, 화자, 발췌 이미지는 저장되지 않음.

배경 이미지와 사용자 업로드 폰트를 사용 중이면 프리셋 데이터에 함께 저장됨. 큰 파일은 브라우저 저장 공간을 많이 사용할 수 있음.

8. 출력 / 저장

카드는 필요한 만큼 조금 늘어난 뒤, 너무 길어지기 전에 본문을 자동 조절해.

9. 백업 / 복원

브라우저 데이터가 지워질 수 있으니 배포판에서는 주기적으로 JSON 백업을 권장함.

서버로 자동 전송하지 않으며, 저장한 발췌와 배경 이미지는 현재 브라우저의 로컬 저장소에 보관됨.
